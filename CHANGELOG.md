# Changelog

## [0.1.0] — 2026-08-21

Первый рабочий релиз. Гейтвей поднимает MCP-серверы, отдаёт их клиенту одним
endpoint'ом, проверяет вызовы по политике и пишет журнал.

### Добавлено

- **Агрегация MCP-серверов** за одним stdio-endpoint: инструменты выдаются с
  неймспейсом (`github__create_issue`), ресурсы маршрутизируются по
  URI-владельцу, промпты — по префиксу имени. Возможности вычисляются из
  реальных downstream'ов, а не объявляются наперёд.
- **Аргументные правила политики** — то, чего не умеет клиентский
  `permissions.allow`: `exact`, `prefix` (по границам компонентов пути, а не
  по строке), `any_of`, `deny_extra_args`. Два режима: `warn` (только
  наблюдение, по умолчанию) и `enforce`.
- **Аудит-журнал** JSONL: канонизованный поднабор аргументов открыто (только
  ключи-идентификаторы, пути усечены, URL сведены к схеме и хосту, похожее на
  секрет отвергнуто), всё остальное — `args_hash`. Ротация по размеру.
- **`zastava learn`** — черновики правил из журнала, включая аргументные
  сужения; **`zastava stats`**, **`events`**, **`annotate`**, **`allow`**,
  **`check`**, **`import`** (перенос серверов из `.claude.json`).
- **Живой reload** политики: правило подхватывается без перезапуска
  MCP-сессии, а ослабление политики отдельно помечается в журнале.
- **Маскировка секретов** для `log.log_args`: секретные ключи, значения вида
  токена и учётные данные в URL заменяются на `<masked>`.
- **Контракт падения**: смерть клиента убивает всё дерево downstream-процессов
  (JobObject на Windows, process session на Unix).
- **Прогресс и `list_changed`** от downstream'ов доходят до клиента; обратные
  запросы сервера (`sampling`, `roots`, `elicitation`) отклоняются честной
  ошибкой, а не выдуманным успехом от имени пользователя.

### Известные ограничения

- Только stdio-транспорт; Streamable HTTP — в планах v0.2.
- Журнал без хэш-цепочки: он показывает, что было, но не доказывает, что его
  не правили.
- Упавший downstream не перезапускается сам — падение видно маркером
  `downstream_failed` в журнале.
- Старт на Windows дороже, чем на Linux (230 мс против 6.7 мс на четырёх
  серверах) — цена обёртки `JobObject`, которой держится убийство дерева
  процессов. Разбор и цифры — в README.
