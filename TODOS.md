## Проверка переносимости: пермишены Cursor / Claude Desktop через Заставу
- **What:** проверить поведение промптов и allowlist-правил в Cursor и Claude Desktop при подключении через Заставу (спайк покрывает только Claude Code).
- **Why:** «переносимость политик между клиентами» — один из четырёх дифференциаторов, невоспроизводимых клиентским `permissions.allow`; без проверки это декларация.
- **Pros:** усиливает главный дифференциатор; расширяет пул потенциальных вторых юзеров.
- **Cons:** у каждого клиента свои квирки пермишенов; легко утонуть в матрице совместимости.
- **Context:** добавлено на eng-review 2026-08-19 (Open Question 3 design-дока). Начать с ручной проверки: тот же zastava.toml, два клиента, наблюдение промптов. Результат — секция compatibility в README.
- **Depends on / blocked by:** M2-lite (нужна работающая агрегация).

## Learn без прокси: standalone-генератор permissions.allow из транскриптов
- **What:** мини-тул (не обязательно Rust), читающий `~/.claude/projects/**/*.jsonl` и генерирующий черновики записей для `permissions.allow` в settings.json — «learn» без гейтвея.
- **Why:** запасной продукт на случай, если контрольное плечо спайка покажет «tool-level тишина уже бесплатна в клиенте»: один вечер, ноль протокольного риска, проверяет тезис policy-once целиком.
- **Pros:** дешёвый хедж главного продуктового риска; частично переиспользует baseline-парсер M1.
- **Cons:** отвлекает от основного проекта, если спайк пройдёт по основной ветке.
- **Context:** идея outside voice на eng-review 2026-08-19 («вариант без прокси»). Активируется веткой спайка «allow без Заставы ≈ Застава».
- **Depends on / blocked by:** Spike (его контрольное плечо решает, нужен ли этот тул).
