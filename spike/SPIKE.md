**Статус автоматики (2026-08-19, выполнено):**

- ✅ Артефакт №0: одобренные промпты **НЕ опознаваемы** в транскриптах (виден только отказ). Метрика перепроектирована: baseline через Notification-хук с matcher `permission_prompt` (событие подтверждено докой hooks).

- ⏳ Baseline 5 дней — стартует после установки хука.

## Ручная часть: три плеча

В каждой папке `testbed/arm-*` запусти `claude`, дай агенту задание:
«вызови tools alpha ping и beta ping с сообщением test, каждый по два раза»
— и запиши, сколько permission-промптов ты увидел и как они выглядели.

| Плечо | Что настроено | Записать |
|---|---|---|
| **arm-a** (статус-кво) | alpha+beta напрямую, БЕЗ permissions | промптов на 4 вызова: ___ |
| **arm-b** (контроль!) | alpha+beta напрямую + `permissions.allow: ["mcp__alpha","mcp__beta"]` | промптов: ___ |
| **arm-c** (Застава) | только proxy + `allow: ["mcp__zastava"]` | промптов: ___ |

Дополнительно в arm-b: проверь гранулярный синтаксис — замени allow на
`["mcp__alpha__ping"]` (tool-level) и посмотри, гасит ли он промпт только этого тула.
Это отвечает на вопрос «может ли клиент гейтить per-tool через префикс сам».

## Интерпретация (ветвление из плана §5)

- **arm-c промптит** → механика тишины мертва → STOP, перецеливание (аудит/learn-продукт).
- **arm-b ≈ arm-c** (оба тихие) → tool-level тишина бесплатна в клиенте → перецеливание
  позиционирования на «аргументная гранулярность + аудит + learn + переносимость»;
  activируется TODO «learn без прокси».
- **arm-b промптит, arm-c нет** → клин «агрегация = тишина» подтверждён → план как есть.

## Baseline-хук (5 дней, до подключения Заставы)

Хук-счётчик permission-промптов: `spike/baseline-hook.ps1` пишет строку в
`~/.zastava/baseline.jsonl` на каждый промпт. Установка — секция hooks в
`~/.claude/settings.json` (см. README-сниппет в этом файле ниже) — ставится
только с твоего согласия, снимается удалением секции.

```json
"hooks": {
  "Notification": [
    {
      "matcher": "permission_prompt",
      "hooks": [
        { "type": "command", "command": "powershell -NoProfile -ExecutionPolicy Bypass -File C:/path/to/zastava/spike/baseline-hook.ps1" }
      ]
    }
  ]
}
```

Через 5 дней: `zastava`-репо, `python spike/baseline-report.py` (появится в M1;
пока достаточно `wc -l ~/.zastava/baseline.jsonl` в день).

## Результаты (прогон 2026-08-19, headless-методика)

**Методика:** интерактивные промпты эмулированы через `claude -p` (Haiku): вызов без
покрывающего правила отклоняется («requested permissions… haven't granted it yet»)
= промптил бы; покрытый правилом выполняется = молчал бы. Плечо A подтвердило
валидность: без правил — блок обоих вызовов.

| Плечо | Результат |
|---|---|
| arm-a (без правил) | оба вызова блокированы — контроль методики пройден |
| arm-b (`allow: ["mcp__alpha","mcp__beta"]`, БЕЗ Заставы) | **оба прошли молча** |
| arm-c (Застава + `allow: ["mcp__zastava"]`) | **оба прошли молча**, прокси работает под живым клиентом |
| arm-b granular (`["mcp__alpha__ping"]`) | alpha прошёл, beta блокирован — **клиент умеет per-tool сам** |
| arm-c granular (`["mcp__zastava__alpha__ping"]`) | alpha прошёл, beta блокирован — **per-tool работает и через Заставу** |

**Найденные по пути баги прокси (починены, коммит ниже):** протокол 2026-07-28
требует `ttlMs`/`cacheScope` в paginated-результатах при `resultType`
(SEP-2549/2322) и `resultType` в tools/call; round-trip через rmcp-структуры
терял их — smoke-тест на старой версии протокола (2025-06-18) этого не ловил.
Урок для M2: прозрачность прокси зависит от версии протокола, conformance-тесты
должны гоняться на версии клиента.

**Вердикт по ветвлению: сработала ветка «arm-b ≈ arm-c».** Tool-level тишина
бесплатна в клиенте (обычный `permissions.allow`), включая per-tool
гранулярность. Механика «агрегация = тишина» работает, но не дифференцирует.
**Перецеливание позиционирования (заготовленная ветка плана): ценность Заставы —
аргументная гранулярность (клиентские правила MCP не матчат аргументы) + аудит-лог
+ `learn` (правила из наблюдений) + переносимость политик между клиентами.**
Tool-level гейт M1 → минимальный/наследует клиенту; приоритет M3 растёт ещё
сильнее; TODO «learn без прокси» повышается из запасного в кандидаты на часть
продукта. Требуется правка design-дока и плана (следующая сессия).

- Артефакт №0: одобренные промпты в транскриптах НЕ опознаваемы → baseline через
  Notification-хук `permission_prompt` (установлен 19.08, копит `~/.zastava/baseline.jsonl`).
- Примечание: интерактивная валидация (руками, 5 минут на плечо C) остаётся
  желательной перед M0, но решающая информация уже получена.
